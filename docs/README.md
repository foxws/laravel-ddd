# Laravel DDD Documentation

Laravel DDD scaffolds a Domain Driven Design (DDD) layer structure for Laravel projects: `ddd:install` wires the layer namespaces into your `composer.json`, and `ddd:make` generates classes into them.

- [Domain Driven Design](domain-driven-design.md) — layers, `ddd:install`, and `ddd:make`.
- [Configuration Reference](configuration.md) — every `config/ddd.php` option.

See the main [README](../README.md) for installation instructions.

Looking for Laravel Essentials' sensible defaults (`Model::shouldBeStrict()`, `URL::forceHttps()`, and friends)? Those live in the separate [foxws/laravel-essentials](https://github.com/foxws/laravel-essentials) package.
